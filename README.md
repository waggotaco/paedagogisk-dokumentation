# Pædagogisk Dokumentationsassistent

Et privat skills-only ChatGPT-plugin til dansk børnehavepraksis.

## Funktioner
- NY OBSERVATION: ottepunkts udfyldningsskabelon
- Fuld pædagogisk dokumentation
- Analyse og refleksion
- Handleplan
- SMTTE
- Evaluering
- Ugentlig opsamling

## Afgrænsning
Plugin'et indeholder kun instruktioner og arbejdsgange. Det har ingen MCP-server, eksterne kontoforbindelser, automatisk datalagring eller journalsystemfunktion. Skabelonen er tekstbaseret i chatten; den opretter ikke en separat formular-app.

## Privatliv
Brug kun oplysninger, som arbejdspladsen har godkendt til den konkrete AI-løsning. Undlad identificerende og fortrolige oplysninger om børn. Pseudonymer er ikke i sig selv en garanti for anonymitet.
